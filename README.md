# Todo App

A simple Todo app built with **HTML, CSS, and JavaScript** to practice DOM manipulation, event handling, and CRUD operations.

## Features

* Create todos
* Read and display todos
* Edit todos
* Delete todos
* Custom edit modal
* Event delegation for todo actions
* Responsive layout

## Tech Stack

* HTML
* CSS
* JavaScript

## What I Practiced

* DOM manipulation
* Event listeners
* Event delegation
* Creating and updating DOM elements
* Working with modal interactions
* CRUD operations

## Future Improvements

* Local storage
* Todo completion status
* Filtering and sorting
* Animations
